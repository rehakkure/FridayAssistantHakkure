# Friday Assistant

Пятница — небольшой голосовой помощник для Windows. Он распознаёт русскую речь через Vosk, отвечает голосом и выполняет простые команды: открывает сайты и приложения, ищет в Google или YouTube, управляет громкостью и вкладками, делает скриншоты, сообщает время и дату.

## Запуск

Нужен Windows и Python 3.11. Установите зависимости и запустите помощника:

```bat
setup.bat
```

Или вручную:

```bat
python -m pip install -r requirements.txt
python friday.py
```

При первом старте программа скачивает русскую модель Vosk (около 40 МБ) с официального сайта проекта. Для работы нужны микрофон, динамики и подключение к интернету при загрузке модели.

Скажите «Пятница», затем команду. Например: «открой YouTube», «поиск в Google погода», «сделай скриншот», «который час» или «выключи компьютер». Выключение ПК ставится с задержкой в 60 секунд; отменить его можно командой «отмена выключения». Значок в системном трее позволяет поставить помощника на паузу или закрыть его.

## Важно

Программа постоянно слушает микрофон и может запускать системные действия по голосовой команде. Выключение и другие действия не требуют дополнительного подтверждения. Скриншоты сохраняются в папку `FridayAssistantShots` на рабочем столе. Учитывайте это, если работаете с конфиденциальными данными.

Проект рассчитан на Windows.
