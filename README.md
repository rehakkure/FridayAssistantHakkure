# Friday Assistant — голосовой помощник для Windows

Friday Assistant («Пятница») - небольшой настольный голосовой помощник. Он распознаёт русскую речь локально с помощью Vosk, отвечает через установленный в Windows механизм синтеза речи и выполняет команды на компьютере.

## Что умеет

- Открывать браузер, YouTube, почту, Яндекс Музыку, Проводник и настройки Windows.
- Искать запросы в Google и на YouTube.
- Управлять вкладками, воспроизведением и громкостью.
- Сообщать дату и время, вычислять простые арифметические выражения.
- Делать снимок экрана и сохранять его в `FridayAssistantShots` на рабочем столе.
- Блокировать компьютер и запускать отложенное на 60 секунд выключение (его можно отменить голосом).
- Работать из системного трея: поставить распознавание на паузу или завершить программу.

## Требования

- Windows 10 или 11.
- Python 3.11 (рекомендуется) и `pip`.
- Микрофон и, если нужен голосовой ответ, динамики/наушники.
- Интернет нужен для первичной загрузки языковой модели и открытия веб-страниц. Распознавание после загрузки модели выполняется локально.

## Установка и запуск

1. Скачайте или клонируйте репозиторий.
2. Запустите `setup.bat`. Скрипт установит зависимости и запустит программу.

Либо выполните команды вручную из папки проекта:

```bat
python -m pip install -r requirements.txt
python friday.py
```

При первом запуске программа загружает русскую модель Vosk в `models/vosk-model-small-ru-0.22`. Загрузка может занять некоторое время. После появления значка в системном трее скажите «Пятница», а затем команду. Некоторые короткие команды можно произносить сразу после активационного слова: «Пятница, открой YouTube».

## Примеры команд

- «Пятница, открой YouTube»
- «Пятница, поиск в Google погода в Москве»
- «Пятница, поиск на YouTube уроки Python»
- «Пятница, сделай скриншот»
- «Пятница, который час»
- «Пятница, открой калькулятор»
- «Пятница, выключи компьютер» - выключение начнётся через 60 секунд.
- «Пятница, отмена выключения»
- «Пятница, помощь»

Полный набор фраз и их варианты описаны в `commands.py`. Распознавание зависит от микрофона и качества речи; распознанные действия могут отличаться от ожидаемых.

## Настройки

Параметры находятся в `config.json`: имя помощника, путь к модели и журналу, адреса загрузки модели, параметры аудио и синтеза речи. Относительные пути считаются от папки проекта. `input_device_index` можно задать индексом микрофона, если автоматически выбран не тот. Индексы доступных устройств записываются в журнал.

Журнал `friday.log` ротируется и не включён в Git. Загруженная модель, временные файлы и результаты сборки также исключены из репозитория.

## Безопасность и конфиденциальность

Программа обрабатывает аудио с микрофона в режиме ожидания активационного слова. Модель распознавания работает локально; распознанный текст записывается в журнал. Интернет-поиск открывает браузер с запросом, поэтому поисковый текст передаётся выбранному сайту.

Голосовые команды могут управлять окнами, делать снимки экрана, блокировать или выключать компьютер. Выключение запускается без отдельного подтверждения, поэтому используйте помощника в подходящей обстановке. Не запускайте его, если нежелательно, чтобы случайно распознанная команда привела к действию. Скриншоты могут содержать личную информацию и сохраняются на рабочем столе.

Модель загружается по HTTPS с указанных в конфигурации адресов; используйте только доверенные адреса. Не помещайте в репозиторий личные журналы, снимки экрана или иные пользовательские данные.

## Структура проекта

- `friday.py` — точка запуска.
- `main.py` — аудио, распознавание речи, системный трей и конфигурация.
- `commands.py` — команды и системные действия.
- `config.json` — настройки по умолчанию.
- `requirements.txt` — зависимости Python.
- `setup.bat` — установка зависимостей и запуск.

## Ограничения

Проект рассчитан на Windows и использует системные функции Windows для сочетаний клавиш, блокировки и выключения. На других операционных системах часть команд не работает. Сборка в `.exe` не входит в стандартный сценарий установки.
